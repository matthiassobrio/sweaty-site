# Site de Sweaty

Site statique (accueil, aide, confidentialité, conditions) servi par GitHub Pages sur https://sweatygame.com (fichier CNAME ; DNS chez Cloudflare, nuage gris).

- Modifier les textes : `build.py`, puis `python3 build.py .`
- Adresse de contact : la constante `CONTACT` en haut de `lang.js` (contact@sweatygame.com, redirigée vers Gmail par Cloudflare Email Routing).
